# stellar-new-dapp

This workspace contains the Stellar frontend challenge Level 1 – White Belt submission.

## Project

The actual project is located in the `stellar-frontend-challenge/` subdirectory.

```bash
cd stellar-frontend-challenge
npm install
npm run dev
```

## What This dApp Does

StellarPay is a simple payment dApp that lets you:
- Connect your Freighter wallet on Stellar Testnet
- View your XLM balance
- Send XLM to any address
- See transaction success/failure with hash
